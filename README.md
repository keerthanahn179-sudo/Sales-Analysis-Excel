# Data Analyst Excel Project

## Project Overview
Sales analysis dashboard created using Microsoft Excel.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data cleaning and analysis

## Analysis
- Total Sales
- Average Sales
- Highest Sales
- Lowest Sales
- Department-wise sales
- Monthly sales analysis

## Dashboard
The project includes a final Sales Analysis Dashboard and a Department Sales by Month chart.
